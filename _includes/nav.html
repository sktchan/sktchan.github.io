{%- comment -%} Nav items come from `nav:` in _config.yml. The site is one scrolling page, so most entries are in-page anchors; only /cv/ is a real URL. Anchors get no active state — that would need scroll-spy, which needs JavaScript, and isn't worth it for five links. A real URL still lights up when you're on it, which is what /cv/ relies on. When you're NOT on the home page, anchors have to be prefixed with "/" or they resolve against the current page and go nowhere. {%- endcomment -%}
{%- assign home = '/' | relative_url -%} {%- for item in site.nav -%} {%- if item.url contains '#' -%} {%- assign target = item.url -%} {%- unless page.url == '/' %}{% assign target = home | append: item.url %}{% endunless -%} {{ item.title }} {%- elsif page.url == item.url -%} {{ item.title }} {%- else -%} {{ item.title }} {%- endif -%} {%- endfor -%}
